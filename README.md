# Git & GitHub Practice

A practice repository created to learn and understand essential **Git and GitHub workflows** through hands-on exercises.

The repository contains multiple exercises covering branching, pull requests, merge conflicts, and basic CI/CD workflows.

---

## What I Practiced

- Creating and managing Git branches
- Committing and tracking code changes
- Creating and reviewing Pull Requests
- Merging branches
- Resolving merge conflicts
- Working with remote repositories
- Using GitHub Actions for basic CI/CD
- Managing React application changes across branches
